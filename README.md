# Dukon — видение системы

Презентация архитектуры **Dukon** (рабочее название). Это операционная система для розницы, которая продаёт через WhatsApp: одежда и товары повседневного спроса, Кыргызстан.

**Смотреть:** https://ssnddsgnr.github.io/Dukon/

> Версия 0.1.0 · черновик · 26.11.2026

## Как смотреть

Презентация занимает один файл `index.html` и не требует сборки или зависимостей. Она открывается в любом современном браузере на компьютере и на телефоне.

| Действие | Компьютер | Телефон |
|---|---|---|
| Следующий слайд | `→`, `Space`, `PageDown`, кнопка → | свайп влево |
| Предыдущий слайд | `←`, `Shift+Space`, `PageUp`, кнопка ← | свайп вправо |
| Первый / последний | `Home` / `End` | — |
| Длинный слайд | колесо мыши вниз | прокрутка вниз |

Шрифты (Onest, Cormorant Garamond, JetBrains Mono) загружаются из Google Fonts. Без интернета вёрстка работает так же, но текст выводится системным шрифтом.

## Исходные документы

Презентация собрана по пакету документов v0.1.0:

- `STACK` — технологический стек и обоснования
- `INVARIANTS` — системные инварианты
- `BLUEPRINT` — общая архитектура, потоки, развёртывание
- `VISION-01` — каталог, склад, приёмка, финансы
- `VISION-02` — заказы, клиенты, сверка оплат, доставка
- `VISION-03` — WhatsApp-шлюз, бот, CRM-инбокс, посты, витрина
- `VISION-04` — платформа: AI-шлюз, события, уведомления, аналитика, доступ, эксплуатация

Если документы меняются, презентацию нужно обновить вручную.

## Обновление

1. Откройте `index.html` в репозитории → значок карандаша, или **Add file → Upload files** с новой версией.
2. Нажмите Commit.
3. GitHub Pages пересоберёт сайт за 1–2 минуты.

## Публикация (однократно)

**Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.**

На бесплатном плане GitHub Pages работает только для публичных репозиториев, поэтому презентацию увидит любой, у кого есть ссылка. Не публикуйте сюда конфиденциальные данные.
